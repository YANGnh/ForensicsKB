# 手机取证分析

## 安卓目录结构

- app：存储手机应用安装包
- data：存储应用数据
- media：存储媒体数据
- misc：存储配置信息
- Android：存储应用附件信息

## 模拟器数据还原

- 源码：*.apk
- 数据库：data文件

先还原data文件，再安装apk

## 安卓蓝牙配置文件

`/misc/bluedroid/bt_config.conf`

## 安卓device_name

```
/system/users/0/settings_global.xml
或者
/adb/lspd/log/props.txt
```

## 系统Linux内核版本号

```
/data/misc/recovery/proc/version
```
