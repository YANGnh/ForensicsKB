# 服务器取证

## web组件（中间件）

- IIS
- Apach 对应配置文件 httpd.conf
- Nginx 对应配置文件 nginx.conf
- Tomcat 对应配置文件 server.xml

## 网站源码

- PHP
- Java
- Python
- asp.net

如何查找配置文件？

1. 方法一：利用源码结构，找文件名——db.config.php database.php config.inc.php system.php等
2. 方法二：使用关键字进行全文内容搜索——host db_host hostname host_name username password db_user db_name db_password等

## 数据库类型

- MySQL
- Oracle
- postgresql
- nosql

## 重构和还原

一些思路：通过history命令，通过netstat查看端口

当网站源码不在默认路径时：

- 重新指定
- 网站源码被删除——backup之类的路径
- 通过磁盘挂载
- 使用jar包或者war包
  - jar包+Nginx+MySQL
  - war包+Tomcat+MySQL

# Docker基础

三大核心：

1. 仓库repository
2. 镜像image
3. 容器container

仓库分为共有仓库和私有仓库，在取证私有仓库时关注以下文件的两个键值，为私有仓库远端地址

```text
/etc/docker/daemon.json
"registry-mirros"
"insecure-registries"
```

## Docker数据管理

本地镜像存储于目录/var/lib/docker文件夹下

## Docker数据提取

dockerfile：单个docker的打包

docker-compose：多个docker的打包

配置文件：docker-compose.yml

```text
find / -name *.yml //全局搜索命令
```

## Docker常用操作

```text
service docker start              //开启docker
docker images                     //所安装的镜像
docker ps -a                      //所有历史进程
docker start 028d                 //运行某个container
docker ps                         //当前运行进程
docker exec -it 028d /bin/bash    //进入某个container的bash
exit                              //退出当前container
docker inspect 028d               //查看某个container的配置
```

docker inspect重点字段：

- Id
- 创建时间（格林威治时）
- "Mounts"
  - "Source": "/docker/conf_01" //配置文件
  - "Destination": "/etc/mysql/mysql.conf.d" //服务器配置文件
- "Data"
  - "UpperDir"
  - "WorkDir"

```text
//Docker pull操作
docker pull XXX
docker run --name mysal_server -P -e  MYSQL_ROOT_PASSWORD=123456 -d mysql
//运行新的容器
//-name别名
//-P随机端口
//-e密码
//-d后台运行、名称
```

# 数据库取证

数据固定：内存中、硬盘中

数据库默认存储路径

**MySQL**

- Windows C:\programdata\MYSQL\Mysql server 5.7.29\data
- Linux /var/lib/mysql/

指令：

```sql
show global variables like '%datadir%'
```

- 二进制日志：记录增删改
- 通用日志：记录增删改查（数据量大）

```sql
show VARIABLES like '%log%' //查看数据库log文件信息
show master status //怎样知道当前的日志
```

```text
mysqldump -uroot -p123456 -A > backup.sql //备份全部数据
mysqld --skip-grant-table //绕过数据库密码，使用之后需要重启数据库服务
```

## 数据库密码绕过

**MySQL**

找到核心mysql的核心配置文件(my.ini)

在核心配置文件底部追加一条命令: skip-grant-tables 越过授权表

```
service mysqld stop  //停止服务
service mysqld start //启动服务
```

**SQL service(windows)**

```text
net stop MSSQLServer            //停止服务
net start MSSQLServer /m SQLCMD //单用户模式启动
```

以管理员权限运行cmd

```text
SQLCMD -A
use[master] //使用主库
go
create login [WIN-KMZ8MFWF5L8\Administrator] from windows with default_database=[master] 
go
exec master..sp_addsrvrolemember @loginame =N ‘WIN-KMZ8MFWF5L8\Administrator’,@rolename =N ‘sysadmin’
go
net stop MSSQLServer  //停止服务
net start MSSQLServer //启动服务
```
