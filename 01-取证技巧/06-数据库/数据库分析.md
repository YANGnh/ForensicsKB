# 数据库取证分析

## 用户授权

```sql
//给所有root用户赋权，外部也可以通过root访问Docker中的mysql数据库
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' IDENTIFIED BY 'password' WITH GRANT OPTION;

//刷新权限
FLUSH PRIVILEGES;
```

## 绕过/重置root密码

Windows是MySQL安装目录下的`my.ini`文件

```sh
my.ini文件添加：
shared-memory
skip-grant-tables

net stop mysql
net start mysql
mysql -u root
update mysql.user set authentication_string = NULL where user = 'root';
FLUSH PRIVILEGES;

//查看远程权限
use mysql;
select user,host from user;

//添加远程权限
update user set host='%' where user='root';
grant all privileges on *.* to root@'%';
FLUSH PRIVILEGES;
```

停止当前运行的 MySQL 实例：

```sh
sudo systemctl stop mysql  # 使用 systemd 的系统（如 Ubuntu、CentOS）
//或者对于较旧版本的 Linux 系统，可以使用以下命令：
sudo service mysqld stop  # 在某些发行版中可能需要使用 mysqld
```

以不加载授权表的方式启动 MySQL：

```sh
在[mysqld]后添加
skip-grant-tablesskip-grant-tablessudo mysqld_safe --skip-grant-tables &
//或者在旧版本的系统上：
sudo /usr/bin/mysqld_safe --skip-grant-tables &

//或找到my.cnf文件
vi /etc/my.cnf
//在[mysqld]后添加
skip-grant-tables
```

重新启动 MySQL 服务：

```sh
sudo systemctl restart mysql
```

连接到 MySQL 数据库：

```sh
mysql -u root
```

重置 root 用户的密码：

```sql
FLUSH PRIVILEGES;
ALTER USER 'root'@'%' IDENTIFIED BY '123456';
ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
exit;
```

使用新设置的密码连接到 MySQL：

```sh
mysql -u root -p
```

结束后删除`skip-grant-tables`并再次重启MySQL避免外部无法连接

## Windows下MySQL常见报错

1. “本地计算机上的MySQL服务启动后停止。某些服务在未由其他服务或程序使用时将自动停止。”
   
   修改my.ini编码为ANSI（记事本打开，另存为，该编码方式）
2. 环境变量
   
   PATH内添加MySQL目录下的bin文件夹路径

## docker环境下绕过/重置root密码

找到docker里的my.cnf

```
find / -name my.cnf //如果出现多个，现在带有merged这个
```

在[mysqld]后添加

```
skip-grant-tables
```

重启docker容器

```
docker restart xxxxxx
docker exec -it xxxxxx bash
```

同上，修改root密码

结束后删除`skip-grant-tables`并再次重启MySQL避免外部无法连接
