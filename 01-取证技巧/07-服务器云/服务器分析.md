## 解决K8s证书过期问题

```sh
//master节点：

cd /etc/kubernetes/pki/
mkdir backup
mv apiserver.crt apiserver-etcd-client.key apiserver-kubelet-client.crt front-proxy-ca.crt front-proxy-client.crt front-proxy-client.key front-proxy-ca.key apiserver-kubelet-client.key apiserver.key apiserver-etcd-client.crt backup
kubeadm init phase certs all

cd /etc/kubernetes/
mkdir backup
mv admin.conf controller-manager.conf kubelet.conf scheduler.conf backup/
kubeadm init phase kubeconfig all

kubeadm certs renew all //旧版本用：kubeadm alpha certs renew all
kubeadm init phase kubeconfig kubelet
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config

systemctl restart kubelet

//master节点处理完毕↑

//master节点传输证书，地址需要替换
scp -rp /etc/kubernetes/pki/ca.key root@192.168.123.152:/etc/kubernetes/pki

//node节点：
//备份旧的配置文件
mkdir -p /tmp/20250703;mv /etc/kubernetes/*.conf /tmp/20250703

kubeadm init phase kubeconfig kubelet

//更新地址为master节点地址
vi /etc/kubernetes/kubelet.conf

systemctl restart kubelet
systemctl status kubelet
```

## laravel php网站架构后台加密代码（盐值）

加密代码路径`/vendor/laravel/framework/src/Illuminate/Hashing/BcryptHasher.php`

```php
//盐值代码
    protected function getSalt() {
        $a = 'sdahjklhl212jkljass';
        $b = hash('sha256', $a, true);
        $c = substr($b, 0, 16);
        $d = base64_decode('xPfGJQaE1zE5d+8=');
        $e = '';
        for($i=0;$i<strlen($d);$i++) {
            $e .= chr(ord($d[$i]) ^ ord($c[$i]));
        }
        return $e;
    }
    
//bycrypt加密验证代码
    public function check($value, $hashedValue, array $options = [])
    {
        $value .= $this->getSalt();
        if ($this->verifyAlgorithm && $this->info($hashedValue)['algoName'] !== 'bcrypt') {
            throw new RuntimeException('This password does not use the Bcrypt algorithm.');
        }

        return parent::check($value, $hashedValue, $options);
    }
    
    //需要跳过密码登录的话，做如下修改，做一个相反值
    return !parent::check($value, $hashedValue, $options);
```
